# E-commerce Platform: Nền tảng thương mại điện tử

## Overview

E-commerce Platform is a multi-vendor e-commerce platform designed with scalability, modularity, and production-ready architecture.

## Tech Stack

- Backend: Spring Boot
- Frontend: Angular
- Database: PostgreSQL

## Project Structure

- docs/: project documentation
- backend/: backend source code
- frontend/: frontend source code
- docker/: container setup

## Workflow

Workflow

This project follows an Agile development model:
Sprint Planning → Development → Daily Standup → Testing → Review → Retrospective
